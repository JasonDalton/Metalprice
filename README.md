# Metal Prices Reference - PWA

A Progressive Web App for quick reference of silver and gold spot prices with fractional sizes and constitutional silver calculations.

## Installation as App

### On Android:
1. Open the site in Chrome
2. Tap the menu (3 dots)
3. Select "Add to Home screen" or "Install app"
4. The app will appear on your home screen with an icon

### On iOS (iPhone/iPad):
1. Open the site in Safari
2. Tap the Share button
3. Select "Add to Home Screen"
4. The app will appear on your home screen with an icon

## App Icons

You need to create two icon files:
- `icon-192.png` - 192x192 pixels
- `icon-512.png` - 512x512 pixels

You can create these using any image editor. Suggested design:
- Gold/silver coin or bar icon
- Simple, recognizable design
- Works well at small sizes

Or use an online icon generator like:
- https://realfavicongenerator.net/
- https://www.pwabuilder.com/imageGenerator

## Features

- Live spot prices from goldapi.io
- Silver and gold reference tables
- Fractional sizes (troy oz and grams)
- Constitutional silver (90% pre-1965)
- Premium calculations (-10%, -5%, melt, +5%, +10%)
- Offline caching
- Auto-refresh every 60 seconds
- Compact mobile-optimized layout
